# IFS UK 2027 counselling landing page

The page sends enquiries to a Netlify Function, which saves them in a Google Sheet. You can view new enquiries in the **UK 2027 Leads** tab. The package uses plain HTML and JavaScript with no dependencies or build step.

## 1. Connect your lead sheet

1. Create a blank Google Sheet in the Google account that should own the leads. Copy the spreadsheet ID from its address, between `/d/` and `/edit`.
2. In the sheet, open **Extensions → Apps Script**. Replace the starter code with the contents of **setup/Code.gs** and save.
3. Open **Project Settings → Script Properties**. Add **SHEET_ID** with the spreadsheet ID. Add **LEAD_SECRET** with a new random password of at least 32 characters generated by your password manager. You will use the same password in Netlify.
4. Select **Deploy → New deployment → Web app**. Choose **Execute as me** and **Who has access → Anyone**. Authorize access with the sheet owner's account. The web app checks the secret before writing. Keep the spreadsheet sharing set to Restricted.
5. Copy the deployed web app URL ending in **/exec**. If your Workspace administrator disables anonymous web apps, this integration needs an account that permits them.

## 2. Upload to GitHub and deploy

1. Extract the ZIP. Create a GitHub repository, select **Add file → Upload files**, then upload the extracted contents. At the top level you should see **public/**, **netlify/**, **setup/** and **netlify.toml**. Commit the files.
2. In Netlify select **Add new project → Import an existing project → GitHub**, authorize the repository and select its production branch. Leave the base directory and build command empty. The included netlify.toml sets the publish directory to **public** and the functions directory to **netlify/functions**.
3. Under **Environment variables**, add **SHEETS_WEB_APP_URL** with your deployed Apps Script /exec URL and **LEAD_SECRET** with the matching password. Include the Functions scope if you select scopes. Use production values for the production deploy. Keep both values out of GitHub.
4. Deploy. After changing environment variables, redeploy. After changing Apps Script, publish a new version through **Manage deployments**.

## 3. Check the live form

Open the Netlify URL with `?utm_source=test&utm_campaign=launch-check`. Enter a test name, email and phone, tick the contact consent box and submit. Confirm the thank-you message appears and one row appears in **UK 2027 Leads** with those campaign values. Marketing consent is separate and optional. The team can follow up from the sheet. This version does not send email notifications.

If the form reports a delivery error, check the /exec URL, web app access, sheet ID and matching secret first. The visitor can retry without retyping. A retry from the same form uses the same submission ID to avoid duplicate rows.

## Campaign settings

Edit the CONFIG block in **public/index.html** to enable a verified WhatsApp number or add advertising pixel IDs. Advertising tags load after the visitor accepts cookies. The published IFS office number and email are used for calls and email. The header uses the company name until you supply an official logo. The original noindex setting is retained for this campaign page.
